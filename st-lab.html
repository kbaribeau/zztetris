    Position and session import / export · Import rejected
      
    JSON snapshots contain the current board, pose, hold, visible queue and optional observed bag evidence. They do not export hidden future pieces. Coaching sessions additionally preserve versioned, validated resource and construction evidence. They exclude Undo history and diagnostic counters. The same Import button also accepts a private practice package: a coaching session bundled with a finite draw sequence. Only six preview pieces reach the coach; Restart replays the exact sequence and Undo rewinds it. Both export buttons exclude private future pieces. Imported supply is finite; no random order is substituted when it ends.
    
      
    Export coaching session downloads the current session without replacing the text below. Imports may provide a suggestedFileName; otherwise the default is st-lab-coaching-export.json. The browser controls the final filename and save location.
    
      
    Legacy st-zero-v1 uses one hold per lock for historical replay. Importing a v1 snapshot into this lab migrates it to unlimited-hold st-zero-v2.
