    Snapshot import / export
      
    JSON snapshots contain the current board, pose, hold, visible queue and optional observed bag evidence. They do not export hidden future pieces. Imported snapshots have a finite queue; no future order is invented when it ends.
    
      
    Legacy st-zero-v1 uses one hold per lock for historical replay. Importing a v1 snapshot into this lab migrates it to unlimited-hold st-zero-v2.
    
      
      
      
    
      
    For legacy board drawing, Fumen tools, redo, gravity and other kicksets, use ordinary practice. Those modes are unchanged.
