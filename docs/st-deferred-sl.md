# Deferred S/L obligations

A projected placement can consume an observed L before its own bag's S enters
preview. Completing an older S with that L transfers the obligation; it does not
prove a debt-free endpoint. Ordinary resource projections now retain that bag's
S with a null identity until actual observation supplies its identity. Deferred L
facts are retained symmetrically for diagnostics; no new L repair strategy or
rejection rule is introduced.

The current obligation Context retains observed counterpart duties and public
inventory. Unknown imported origins do not acquire known bag obligations. No
private generator, unseen order, guessed arrival time, or extra preview enters
search. Native schema-v2 sessions serialize these current facts directly; old
action-tape sessions are rejected rather than silently dropping obligations.
Current notch checkpoints and independently validated finite advice remain
portable. Undo, hidden future and displayed counters are not session exports.

Regression fixtures in `test/fixtures/deferred-sl-reveals.json` contain public
requests and legal recorded witnesses from revision 08351b3, seeds 2718286055,
2718288073 and 2718289082. They do not contain private input streams. The tests
compare the same checked path before/after the real S reveal, replay derived
history through JSON transport, and cover legitimate accommodation and no
fabricated obligations for consumed counterparts or unknown imports.

This corrects the certificate model, not a promise of improved run length.
Unseen S obligations cannot be claimed repaired by a finite visible prefix, so
some previously admitted plans may now be withheld. Opening allocation policy,
Reset logic, live planner limits and structural ranking are unchanged.
