## Work-package details and boundaries

- Pure JavaScript browser/CommonJS modules replace the suggested TypeScript build to fit this static repository. The same code runs in worker and headless tests; UI code never defines strategy.
- The explicit game contract differs from ordinary practice: zero gravity, SRS+ and one hold per lock in the lab only. Ordinary engines, rotations and Fumen exports are unchanged.
- Left/center/right predicates are deliberately small: left roughness/closed damage, center height and partner deficit, channel separation, headroom, geometric obligations, and independently checked hypothetical T entry. No phase script or fixture-ID answer table is consulted.
- Actual prefix search allocates pieces through real hold/draw transitions. A single hypothetical T-entry proof does not certify every geometric cavity, satisfy two obligations with one T, or assert the T will arrive. Compatibility is proved only for pieces actually placed in the checked continuation.
- Empty-board opening, left-side coaching and arbitrary damaged-stack recovery remain outside the declared profile. A healthy two-high left base, temporary regional imbalance, and a depleted one-high left base beneath a remaining center of at least five rows are admitted for bounded recovery; the returned endpoint must restore strict support. a very sparse stack after successful clears may leave the established-stack scope. That is an explicit scope stop, not top-out or proof no continuation exists.
