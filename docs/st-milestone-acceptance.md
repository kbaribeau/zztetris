## Work-package details and boundaries

- Pure JavaScript browser/CommonJS modules replace the suggested TypeScript build to fit this static repository. The same code runs in worker and headless tests; UI code never defines strategy.
- The lab's explicit game profiles and migration contract are defined in the [rules contract](st-rules-contract.md). Ordinary engines, rotations and Fumen exports are unchanged.
- Left/center/right predicates remain deliberately small. `st-structure.js` adds local SL/OJ completion geometry, regional role/repair burdens and piece-instance allocation; `st-planner.js` ranks continued structure and headroom ahead of tactical events and tracks losing a prepared scoring shape as repair debt. No phase script or fixture-ID answer table is consulted. See `st-regional-feedback.md` for the eight existing development regressions, remaining alternative choices and explicit limitations.
- Actual prefix search allocates pieces through real hold/draw transitions. A single hypothetical T-entry proof does not certify every geometric cavity, satisfy two obligations with one T, or assert the T will arrive. Compatibility is proved only for pieces actually placed in the checked continuation.
- The current maintenance admission boundaries and exclusions are defined in [ST lab](../ST-LAB.md#architecture-and-information-contract). Separate bounded empty-board coaching has its own [opening scope and handoff contract](st-opening.md); it does not establish general recovery or full Reset control.
